# Постоянная подпись APK

## Первичная настройка (однократно)

1. Создать fine-grained personal access token на GitHub, выбрав только этот репозиторий, срок действия — минимальный, Repository permissions → Secrets: Read and write.
2. В Settings → Secrets and variables → Actions создать секрет SIGNING_SETUP_TOKEN с этим токеном.
3. Создать секрет KEYSTORE_PASSWORD с уникальным случайным паролем длиной не менее 24 символов. Сохранить пароль в менеджере паролей. Не передавать его в чате и не вводить в параметры запуска workflow.
4. Actions → Generate Signing Key → Run workflow (main).
5. После успеха скачать артефакт encrypted-signing-backup, распаковать внешний ZIP и сохранить зашифрованный signing-backup.7z в надёжном месте. Внутренний архив защищён паролем KEYSTORE_PASSWORD, содержит schedule-tgu.p12. Не публиковать архив и пароль. Артефакт хранится один день; удалить его после скачивания.
6. Убедиться, что появился секрет KEYSTORE_BASE64. Удалить SIGNING_SETUP_TOKEN из Secrets и отозвать токен на GitHub.
7. Actions → Build Android APK → Run workflow (main).

## Последующие сборки

CI декодирует ключ во временный файл, проверяет его, собирает assembleRelease, проверяет подпись apksigner, удаляет временный ключ и публикует APK. При отсутствии ключа сборка релиза прекращается; отладочная подпись не используется как запасной вариант.

Не менять KEYSTORE_PASSWORD, alias schedule-tgu или ключ без восстановления оригинального хранилища. Повторный запуск генератора при существующем KEYSTORE_BASE64 запрещён. Потеря ключа означает невозможность обновления установленного приложения прежней подписью.

## Восстановление

Из сохранённого signing-backup.7z извлечь schedule-tgu.p12 с оригинальным паролем. Восстановить KEYSTORE_PASSWORD и KEYSTORE_BASE64 (Base64 содержимого p12 без переводов строк) в Secrets. Никогда не создавать новый ключ вместо утраченного, если требуется сохранить совместимость подписи.

## Миграция

APK 0.6.0 и более ранние сборки подписывались отладочным ключом. Для перехода на 0.7.0 с постоянной подписью потребуется удалить старую установку, что удалит её локальные настройки и кеш. После установки заново выбрать преподавателя и разрешить уведомления/точные будильники.
